# Page text and translation (B4, ID-49)

**Status:** done 2026-10-15. English is the only language in v1 (Q9). All text people see is in one file, so adding a language is a translation job, not a code change.

## Where the words live

| What | Where | How code reads it |
|---|---|---|
| Page and component text | `src/messages/en.json`, one section per screen or component (`agencyOnboarding`, `bulkInvite`, …) | `useTranslations("section")` in components; `await getTranslations("section")` in async server pages |
| Names for database codes (statuses, roles, document types, request types) | `en.json` → `labels` | `useLabels()` (`src/i18n/labels.ts`) or `await getLabels()` (`src/i18n/labels-server.ts`) |
| Page titles | `en.json` → `meta` | `export const generateMetadata = titled("key")`; layouts use `section("key")` (`src/i18n/metadata.ts`) |
| Pop-up messages, form problems and errors from server actions | `en.json` → `server.done`, `server.invalid`, `server.errors` | `const t = await serverText()` then `t.done("key")`, `t.invalid("key")`, `t.error("key")`; zod messages use `k("key")` (`src/server/i18n.ts`) |
| Status colours | `src/lib/status.ts` (`statusTone`) | colours only, no words |

Keys are **typed** (`src/global.d.ts`): a missing or misspelt key fails `pnpm typecheck`.

## Writing rules

- Plurals and numbers use ICU: `"{count, plural, one {# invitation} other {# invitations}}"`.
- Bold or coloured words inside a sentence use rich text: `"Press <b>Send</b>"` with `t.rich("key", { b: (c) => <strong>{c}</strong> })`.
- Never build sentences by joining pieces in code; put the whole sentence in the file with `{placeholders}`.
- Dates use `formatDate` and `timeAgo` with the viewer's locale.

## Adding a language

1. Copy `src/messages/en.json` to `src/messages/<locale>.json` and translate the values (keep the keys).
2. Choose the locale in `src/i18n/request.ts` (from a cookie or the user's profile) and add it to `Locale` in `src/global.d.ts`.
3. Translate the items below that are still English.

## Still English (not page text)

| Item | Where | Note |
|---|---|---|
| Messages written by database rules (CG codes, e.g. "Upload a new Owner ID before sending your application back.") | `supabase/migrations/*` | Shown as they come. To translate, map each CG message to a key in the app, or return a key from the database. |
| Emails | `src/server/email/templates.ts` | One file; move to messages when a second language is added. |
| Country names | `src/lib/countries.ts` | Fixed list (it keeps server and browser identical). Use `Intl.DisplayNames` per locale later. |
| CSV column names (import sample and export) | `src/lib/bulk-invite.ts`, `/agency/members/export` | Kept as fixed English keys so files work in every language. Values (role, status) are translated in the export. |
| Demo data on the homepage board | `src/components/landing/pulse-board.tsx` | Numbers and shapes only; all labels are translated. |
