# CohortGlobal — Implementation Decisions

Last updated: 2026-10-13, session 3 (Phase 1 build)

These are the technical choices made while building Phase 1. They are **not** owner decisions; those live in `confirmed-decisions.md`, which wins if the two ever disagree.

Each row has a level:

- **Critical:** changes what people can do or see, or is hard to undo. Built in a reasonable default, flagged for the owner, and listed as an open question (Q28–Q31) in `confirmed-decisions.md`.
- **Medium:** a product or design choice the owner may want different. Easy to change; the "How to change" column says where.
- **Low:** internal engineering detail.

Where a rule lives in the database, changing it means a new migration (never edit an applied migration), plus a pgTAP test.
